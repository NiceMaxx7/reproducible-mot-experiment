# Reproducible Research Artifact Bundle

Повний відтворюваний пакет обчислювального експерименту (Практична робота №6 з курсу «Методологія та організація наукових досліджень», Хмельницький національний університет).

## Структура проєкту

- `data/dataset.csv.dvc` — метадані версіонованого датасету під керуванням **DVC**;
- `train.py` — скрипт навчання моделі з автоматичним логуванням параметрів, метрик та артефактів у **MLflow**;
- `requirements.txt` — зафіксовані версії Python-залежностей;
- `Dockerfile` — конфігурація ізольованого образу середовища виконання;
- `docker-compose.yml` — оркестрація контейнерів експерименту та сервера **MLflow Tracking**;
- `zenodo.json` — машинозчитувані наукові метадані за стандартами **FAIR Data**.
